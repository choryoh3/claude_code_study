# UIを確認する

1. `pnpm dev` を起動する（起動済みならそのまま使う）
2. Playwright MCPで対象ページを開き、次の組み合わせでスクリーンショットを撮る
   - ライト/ダーク × モバイル(390px)/デスクトップ(1280px)
3. 次を確認する
   - 余白・タイポ・色がデザインシステムのトークンに沿っている
   - フォーカスリング、キーボード操作、コントラスト(WCAG AA)
   - ロード・空・エラーの各状態
   - `prefers-reduced-motion` で動きが抑えられる
4. 問題を箇条書きにして修正し、再度撮影して確認する
