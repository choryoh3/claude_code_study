## ゴール

- スラッシュコマンドとは何かを説明できる
- コマンドの探し方を知り、最初に使う数個のコマンドを使い分けられる
- 会話の管理（クリア・圧縮・再開）の入口を理解する

## 前提

- [基本操作](/learn/basic/basic-usage)のレッスンを終えている
- `claude` を起動してセッションに入れる

## 解説

### スラッシュコマンドとは

セッション内で `/` から始めて入力する、Claude Code 自体を操作するための命令です。モデルの切り替え、会話のクリア、設定の変更などを素早く行えます。次の点を押さえてください。

- `/` を入力すると候補が表示され、続けて文字を打つと絞り込めます
- コマンドは**メッセージの先頭**でのみ認識されます。名前の後ろの文字は引数になります
- 候補には組み込みコマンドのほか、スキル（手順化された作業）も混ざって出ます
- コマンドは更新で増減します。最新の一覧は `/help` と公式の commands ページで確認してください

### 最初に覚えるコマンド

| コマンド       | 役割                                                                      |
| -------------- | ------------------------------------------------------------------------- |
| `/help`        | ヘルプと利用可能なコマンドの表示                                          |
| `/clear`       | 空のコンテキストで新しい会話を始める（別名 `/reset`、`/new`）             |
| `/compact`     | 会話を要約してコンテキストを空ける。`/compact` の後ろに要約の観点を書ける |
| `/context`     | コンテキストの使用状況をグリッドで可視化する                              |
| `/resume`      | 過去の会話を再開する（セッション選択画面を開く）                          |
| `/model`       | モデルを切り替える。引数なしで選択画面を開く                              |
| `/config`      | 設定画面を開く（別名 `/settings`）                                        |
| `/status`      | バージョン、モデル、アカウント、接続状態を表示する                        |
| `/usage`       | セッションの費用、プランの利用上限、利用状況を表示する（`/cost` は別名）  |
| `/init`        | プロジェクト用の `CLAUDE.md` を作る                                       |
| `/memory`      | `CLAUDE.md` を編集する                                                    |
| `/permissions` | 許可・確認・拒否のルールを管理する                                        |
| `/rewind`      | 会話やコードを以前の時点へ戻す                                            |
| `/exit`        | 終了する（別名 `/quit`）                                                  |

### `/clear` と `/compact` の違い

どちらも「コンテキスト（Claude が一度に覚えておける会話の量）」を空ける目的で使いますが、動作が違います。

- `/clear`: 会話を捨てて、新しく始める。無関係な作業に移るとき向き。前の会話は `/resume` で戻れる
- `/compact`: 会話を要約して、**同じ会話を続ける**。長い作業の途中向き

詳しくは[コンテキスト管理](/learn/basic/context-management)のレッスンで扱います。`/init`・`/memory` は[CLAUDE.md](/learn/basic/claude-md)、`/permissions` は[権限モード](/learn/basic/permission-modes)の回で改めて学びます。ここでは「存在する」ことだけ覚えれば十分です。

## ハンズオン

1. `claude` を起動し、`/` だけを入力します。

   ```text
   /
   ```

   期待される結果: 利用可能なコマンドの候補が表示されます。`co` と続けると絞り込まれます。Esc で閉じます。

2. ヘルプを見ます。

   ```text
   /help
   ```

   期待される結果: ヘルプと利用可能なコマンドが表示されます。

3. 状態を確認します。

   ```text
   /status
   ```

   期待される結果: 設定画面が Status タブで開き、バージョン・モデル・アカウントが見えます。Esc で閉じます。

4. 何か1つ質問したあと、コンテキストの使用状況を見ます。

   ```text
   /context
   ```

   期待される結果: 使用量が色付きのグリッドで表示されます。

5. 会話を要約し、続いてクリアします。

   ```text
   /compact
   ```

   ```text
   /clear
   ```

   期待される結果: `/compact` の後も会話は続き、`/clear` の後は空の新しい会話になります。

6. `/resume` を実行し、クリア前の会話が一覧に出ることを確認して Esc で閉じます。最後に `/exit` で終了します。

## よくある失敗

- **コマンドが効かず、普通の文章として扱われる**
  - 原因: 文の途中に書いている。コマンドは先頭でのみ認識される。
  - 対処: メッセージの先頭に `/` から書く。
- **ネットの記事にあるコマンドが存在しない**
  - 原因: バージョンによってコマンドが追加・変更される。
  - 対処: `/` の候補か `/help`、公式の commands ページで現行の一覧を確認する。
- **`/clear` で会話が消えたと焦る**
  - 原因: `/clear` は新しい会話を始めるコマンド。
  - 対処: `/resume` で前の会話を再開できる。
- **`/model` で変更したモデルが次回以降も残る**
  - 原因: `/model` は選んだモデルを新しいセッションの既定値として保存する。
  - 対処: 選択画面で対象の行に `s` を押すと、そのセッションだけの切り替えにできる。
- **`/cost` と `/usage` を別物だと思う**
  - 原因: `/cost` は `/usage` の別名。
  - 対処: どちらでも同じ画面が開く。
